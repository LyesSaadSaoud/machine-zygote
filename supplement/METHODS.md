# Supplementary Methods

Everything below describes the code in this repository exactly. Symbols match
`src/`. All parameter values are in `src/config.py` and `src/soma.py`; the
values used for the shipped results are recorded in each
`outputs/raw/*_provenance.json`.

---

## 1. Individual, germline and soma

An individual is `M = (G, S)`.

`G ∈ [−1, 1]^d` is the germline in **normalised locus coordinates**, `d = 102`.
Each locus has a declared range `[lo, hi]` and an inheritance channel
(`src/germline.py`). Denormalisation is affine:
`p = lo + (u+1)/2 · (hi − lo)`.

| block | size | range | channel | role |
|---|---|---|---|---|
| `W` | 64 (8×8) | [−0.50, 0.50] | autosomal | regulatory coupling matrix |
| `lam` | 8 | [0.50, 2.00] | autosomal | gene-product decay |
| `b` | 8 | [−0.60, 0.60] | autosomal | constitutive gene bias |
| `s0` | 8 | [−0.80, 0.80] | autosomal | zygotic determinant (uniform input) |
| `morph` | 8 | [−1.00, 1.00] | autosomal | sensitivity to the positional morphogen |
| `D_diff` | 1 | [0.00, 0.50] | autosomal | inter-module diffusion of gene products |
| `kappa_J` | 1 | [0.15, 1.00] | autosomal | coupling gain of the developed connectome |
| `fate_temp` | 1 | [0.50, 2.00] | autosomal | fate-commitment threshold (softmax temperature) |
| `T_dev` | 1 | [12.0, 36.0] | **maternal** | developmental duration |
| `sigma_dev` | 1 | [0.010, 0.060] | **maternal** | developmental noise amplitude |
| `morph_steep` | 1 | [0.60, 2.50] | **maternal** | morphogen gradient steepness |

The maternal channel is the cytoplasmic-deposit analogue. It is the reason a
reciprocal cross *can* differ from its mirror; whether it *does* is measured,
not assumed.

### Founders

Founder `k` is `amp · h_{k+1}` where `h` is a row of a Sylvester Hadamard
matrix truncated to `d` and `amp = 0.7`. Row 0 (all ones) is skipped. Every
founder therefore has identical per-locus magnitude — no founder is "stronger"
— and distinct rows are orthogonal at full length. The realised pairwise
distances are measured and reported rather than asserted.

The random-germline control (Condition 4) sets each locus to `±amp` with equal
probability: identical dimension, identical per-locus magnitude, identical
norm, random direction.

## 2. Reproduction

Gametes: `g = clip(G + ξ, −1, 1)` with `ξ ~ N(0, σ_mut²)`, `σ_mut = 0.05` in
normalised units, drawn independently for each parent.

Recombination: for autosomal loci the zygote takes the dam's gamete with
probability 0.5, otherwise the sire's; maternal-channel loci always come from
the dam.

`src/zygote.py` bundles the recombination mask, both mutation vectors and the
developmental-noise seed into a `Background`. Given a fixed background the
zygote is a deterministic function of the two parental germlines — this is what
makes the swap in exp02 an intervention rather than a re-sample.

A clone cross `A × A` is *not* a copy: the two gametes carry independent
mutations, so within-line variation is generated by exactly the same mechanism
as in an outcross.

## 3. Development

The generic soma `U`: `N = 8` modules with regulatory state identically zero,
distinguished only by a position `p_m ∈ linspace(−1, 1, N)`.

Every module runs the same zygotic network. With
`s_i^(m) = s0_i + morph_i · tanh(morph_steep · p_m)`:

```
dz_i^(m)/dt = −λ_i z_i^(m)
              + tanh( Σ_j W_ij z_j^(m) + b_i + s_i^(m) )
              + D·(z^(m−1) + z^(m+1) − 2 z^(m))_i
              + σ_dev · dW_t
```

Integration: Euler–Maruyama, `dt = 0.05`, no-flux (Neumann) boundaries on the
body axis, per-individual duration `T_dev`. The state at `T_dev` is **frozen**
and is the only thing the soma read-out may see.

Ablations:

* `nodev_static` — frozen state `= s0` in every module. No dynamics, no
  positional information. This is Condition 5 as literally specified.
* `nodev_quasistatic` — frozen state `= tanh(b + s^(m)) / λ`. Positional
  information is read out but there is no recurrent dynamics, no diffusion, no
  noise and no developmental time. This is the *informative* control, because
  `nodev_static` cannot assign distinct fates by construction.

## 4. Differentiation (fixed read-out)

Non-heritable and identical in every condition (`src/soma.py`):

```
logits_m = FATE_GAIN · ( z^(m)[0:5] − mean_m z^(m)[0:5] )
pi_m     = softmax( logits_m / fate_temp )                    FATE_GAIN = 5
w_m      = 1.30 + 0.70 · sigmoid(z^(m)[5])
g_m      = 1.00 + 2.00 · sigmoid(z^(m)[6])
tau_a,m  = (1.50 + 2.50 · sigmoid(z^(m)[7])) · (1 + 1.5·pi_m[memory])
bias_m   = 0.20 · (pi_m[memory] − 1/5)
J_mn     = kappa_J · ⟨z^(m), z^(n)⟩/K · (0.5 + 1.5·pi_n[inter]) / (N−1),  J_mm = 0
```

Fate logits are mean-subtracted across modules: a module's fate is decided by
how it differs from the body-wide average (a lateral-inhibition analogue).
A consequence worth stating: if development leaves all modules identical, the
logits vanish and every module stays uncommitted — which is the correct
degenerate behaviour, and is what `nodev_static` exhibits.

The connectome rule is a chemoaffinity analogue: modules with aligned
expression profiles couple positively, opposed profiles negatively.
Connectivity is a developmental product, never an inherited matrix.

The isolated-unit ranges keep a unit generically on the oscillatory side of its
Hopf bifurcation (`g > w − 1` and `tau_a > tau_u/(w − 1)` hold across the whole
box), so newborns are not universally motionless. This is an a-priori modelling
choice to avoid a floor effect, not a hypothesis-directed adjustment.

## 5. Newborn evaluation

```
tau_u du_m/dt = −u_m + w_m r_m + Σ_{n≠m} J_mn r_n + bias_m + I_m − a_m
tau_a,m da_m/dt = g_m r_m − a_m ,        r_m = tanh(u_m)
I_m = sens_gain_m · exp(−‖(x,y) − light‖² / (2 σ_L²))
wheel_{L,R} = v_max · clip(slope · Σ_m mot_{L,R},m r_m, 0, 1)
v = (wheel_L + wheel_R)/2 ,   omega = (wheel_R − wheel_L)/wheel_base
dx = v cos θ,  dy = v sin θ,  dθ = omega
```

Heun (RK2), `dt = 0.05`, `t_total = 200`, traits measured after a transient of
30. The initial condition is identical for every individual in every condition
(`u_m(0) = 0.05·cos(π(m+½)/N)`, `a = 0`, pose at the origin), so all
behavioural differences are attributable to the developed soma.

Motor pools are **rectified**: a wheel can only be driven forward, as a muscle
can only pull. A silent motor pool therefore yields a motionless newborn rather
than a fixed half-speed cruise (see the pilot disclosure in
`configs/preregistration.md`).

**No learning.** No weight, gain, time constant or bias changes during
evaluation. `tests/test_determinism.py` asserts that the controller parameter
vector is bitwise identical before and after simulation, and audits the AST of
`embodiment.py`, `phenotype.py` and `soma.py` for learning-like identifiers.

### Traits

1. **speed_mean** — time average of `v` over the measurement window.
2. **gait_freq** — peak of the module-averaged power spectrum (Hann window,
   4× zero padding, parabolic refinement in log power), restricted to
   frequencies with at least two cycles in the window. Averaging spectra across
   modules means antiphase modules do not cancel.
3. **turn_bias** — signed time average of `omega`.
4. **recovery_time** — see below.
5. **coherence** — amplitude-weighted Kuramoto order parameter of the Hilbert
   phases of the module activities, averaged over time. Amplitude weighting
   stops silent modules injecting random phases.
6. **explore_radius** — maximum displacement from the start position.

### Perturbation recovery

Each individual is simulated as a twin pair; at `t_perturb = 100` the perturbed
twin receives `0.5·cos(π(m+½)/N)` added to `u`.

A generic impulse to a limit cycle causes a **permanent phase shift**, so the
twin state distance never decays and any criterion built on it censors nearly
everyone. Recovery is therefore measured **transversally**: the distance from
the perturbed state to the nominal orbit, represented as the point cloud of
nominal states over the pre-impulse steady window (160 points in the 16-D
`[u | a]` space). The nominal twin's own distance to that cloud is subtracted
as a baseline (it is not exactly zero, because the robot keeps moving through a
position-dependent sensory field), and distances are normalised by the orbit's
radius of gyration.

Recovery is the first time the excess deviation drops below 10 % of its
post-impulse peak and stays there for 8 time units. Individuals that never do
are **censored at 90 and flagged**, never dropped; the censoring rate is a
reported outcome.

## 6. Statistics

`statsmodels` is not assumed present; everything is implemented on
numpy/scipy in `src/statistics.py`.

* **Two-way ANOVA** — balanced fixed-effects with interaction, dam × sire.
  Balance is asserted, not assumed, so Type I = II = III. Reported with `F`,
  parametric `p`, partial η², ω², and sum-to-zero effect estimates.
* **Permutation tests** — 5000 permutations. For a main effect, labels of that
  factor are permuted *within* levels of the other, which is exchangeable under
  the joint null of no effect and no interaction. The interaction uses
  ter Braak residual permutation on the additive model and is labelled
  approximate.
* **Bootstrap** — 5000 within-cell resamples for effect estimates, differences
  of means and PDVF.
* **Multiple comparisons** — Holm–Bonferroni across the six traits within each
  hypothesis family.
* **Effect sizes** — Hedges' *g* for pairwise contrasts, partial η² for ANOVA
  terms, multivariate centroid distance in pooled-SD units. No p-value is
  reported without one.

### PDVF

```
V_dam  = max((MS_dam  − MS_res)/(n·b), 0)
V_sire = max((MS_sire − MS_res)/(n·a), 0)
V_int  = max((MS_int  − MS_res)/n,     0)
PDVF   = (V_dam + V_sire + V_int) / (V_dam + V_sire + V_int + MS_res)
```

**PDVF is not narrow-sense heritability.** There is no additive genetic model,
no breeding population, no environmental variance component in the
quantitative-genetic sense, and the parents are four fixed founders rather than
a random sample. A descriptive R²-style value is reported alongside, and
truncating negative components at zero introduces a small upward bias which is
stated rather than hidden.

## 7. Reproducibility

`MASTER_SEED = 20260823`. Every stream is `default_rng(BLAKE2b(master, labels))`
— stable across processes, platforms and Python versions, unlike `hash()`.
Each individual's developmental noise is keyed on its own seed, never on batch
position, so chunk size cannot alter a result (asserted by a test). Every raw
file carries Python version, package versions, git commit and dirty flag, seed,
full config, config digest, hardware and timestamp.

## 8. Limitations

1. **Simulation only.** No physical robot, no physical measurement, no physical
   validation. "Heredity" here is a property of a computational architecture.
2. **`nodev_static` is partly structural.** With every module identical no fate
   can be assigned, so part of its collapse follows from the construction
   rather than from an empirical finding. `nodev_quasistatic` is the
   informative ablation and is the one H2 is judged on.
3. **Four fixed founders.** The diallel is a fixed-effects design over four
   specific genomes; PDVF describes *this* design and does not generalise to a
   population parameter.
4. **No selection anywhere.** The multigeneration experiment shows drift,
   recombination and developmental noise. It is not evolution and is not
   described as such.
5. **The developmental read-out is hand-designed.** It is fixed and
   non-heritable, which is what keeps the germline from being a disguised
   controller, but its functional form is a modelling choice; a different
   read-out could change the quantitative results.
6. **One body plan and one environment.** All traits come from a single
   differential-drive abstraction in a single standardised sensory field.
7. **Recovery time is censored for some individuals.** Censoring is reported,
   not removed; treating censored values as `recovery_censor` compresses the
   upper tail of that trait.
8. **The pilot changed three model components** before the hypotheses were
   tested. These are disclosed in full in `configs/preregistration.md`. They
   were made on non-degeneracy grounds, but a reader who disagrees with that
   judgement should treat the affected traits accordingly.
